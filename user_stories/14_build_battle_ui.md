## Title
Build the battle UI foundation based on the selected background

### User Story
As a player,  
I want to see a complete battle screen with a thematically fitting background,  
so that combat feels immersive and all important battle elements are clearly displayed.

### Description
The battle screen should now be implemented as a complete UI foundation.  
The already selected background will be used as the visual base.  
All further battle elements such as health displays, card areas, decks, and monster and player information should be adapted to this background and integrated into it in a meaningful way.

This user story creates the foundation for all later visual extensions such as card illustrations, animations, and effects.

### Acceptance Criteria
- The selected background is integrated as the base of the battle screen.
- The battle screen has a clear structural UI foundation for combat.
- There are visible areas for the player and the monster.
- There are dedicated UI areas for HP and other important battle values.
- There are dedicated areas for the hand, deck, and central battle information.
- All UI elements visually align with the chosen background.
- The new UI structure provides a stable foundation for later extensions.

### Tasks
- [ ] Integrate the selected background into the battle screen.
- [ ] Adapt the basic battle screen structure to the background.
- [ ] Place areas for player and monster information.
- [ ] Define areas for HP and other battle values.
- [ ] Create areas for deck, hand, and central information panels.
- [ ] Add first matching styles for panels, frames, and UI fields.
- [ ] Check that the new structure works together with the current battle flow.
