# User Story 1: Start a New Game

## Title
Start a new game

## User Story
As a player,  
I want to start a new game,  
so that I can begin a fresh run.

## Description
The game should provide a way for the player to start a new run.  
When the game starts, the initial game state should be created and the player should be taken into the game flow.

## Acceptance Criteria
- A start screen is shown when the app loads.
- The player can click a **Start Game** button.
- After clicking the button, a new game session begins.
- The initial game state is created.
- The player is taken to the next game view.

## Tasks
- [ ] Create a start screen component.
- [ ] Add a **Start Game** button.
- [ ] Create a function to initialize a new game state.
